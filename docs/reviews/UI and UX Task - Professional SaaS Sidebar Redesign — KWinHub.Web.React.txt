### Interaction rules

- Active page: one clearly selected item; if it belongs to a collapsed group, automatically expand that group.
- Group collapse: preserve user choices when navigating between pages, except that the active page's group must remain visible.
- Compact mode: use tooltips, accessible names, and a visible expand/collapse control.
- Scrolling: keep the brand header and footer fixed while the navigation list scrolls independently.
- Responsive layout: do not let the sidebar squeeze the athlete table excessively on smaller desktop displays.
- Permissions: retain the existing `canAccess()` filtering and make sure hidden destinations are not exposed by the compact mode.

## 5. Specific code-level issue to address

In the current `Sidebar.tsx`, the effect that automatically expands the active navigation group depends only on `currentView`:

```
useEffect(() => {
  const activeGroup = groups.find(isGroupActive);
  if (activeGroup && collapsedGroups[activeGroup.id]) {
    setCollapsedGroups((prev) => ({
      ...prev,
      [activeGroup.id]: false,
    }));
  }
}, [currentView]);
```

However, it also reads `groups` and `collapsedGroups`, which are derived from other state and functions. That can produce stale-closure or hook-dependency lint concerns.

Ask the coding agent to refactor this carefully, preferably deriving the active group from the current view and ensuring the active group is expanded without unnecessarily resetting the user's other collapse choices. Verify that switching between athlete list and athlete detail views still highlights the correct navigation item.

Use a refined, restrained visual style:

1. Keep all existing navigation destinations and permission checks.
2. Keep the current group taxonomy and order unless there is a compelling, documented UX reason to adjust labels.
3. Keep the brand header visually aligned with the app's top header.
4. Make the navigation list independently scrollable.
5. Keep the footer compact so it does not consume excessive vertical space.

- Use a consistent item height of approximately 36–40px.
- Use 16–18px icons with consistent alignment.
- Use readable 10–11px group headings with consistent spacing.

- Keep active-page styling subtle but unmistakable: a restrained green-tinted surface and/or narrow accent indicator.
- Keep group expand/collapse controls accessible and visually consistent.
- Preserve the user's collapsed-group preferences while ensuring the active page's group is expanded.

- Ensure all sidebar surfaces, text, borders, hover states, and active states work in both Kunwei Classic and Performance Light.

- Use native buttons for interactive navigation items.
- Provide accessible labels for icon-only controls.
- Support keyboard operation and visible focus.
- Respect reduced-motion preferences.
- Avoid relying on color alone for active navigation.

Do not change API calls, routes, view names, authorization rules, page content, or business logic. Do not remove existing destinations to shorten the sidebar. Preserve logout behavior.
